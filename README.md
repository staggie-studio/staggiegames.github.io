# Staggie Games Website

## Deploy
1. Put every file in the root of the GitHub repository.
2. Open **Repository → Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Set the custom domain to `staggiegames.com`.
6. Configure the Namecheap DNS records for GitHub Pages.
7. After DNS propagation, enable **Enforce HTTPS**.

## Store URLs
- Privacy Policy: `https://staggiegames.com/privacy.html`
- Privacy Choices: `https://staggiegames.com/privacy-choices.html`
- Support: `https://staggiegames.com/support.html`

The Privacy Policy link must also be accessible from inside each game.
